AVD ServiceNow bridge

Map avd-current-state C11/C21/C24 artifacts into ServiceNow CMDB IRE, Problem, Change, and avd-swarm V1-4 incident workflows.

      1. CMDB & CSDM IRE Preview

      Transform a C11 (avd-current-state-facts) snapshot into a ServiceNow Identification and Reconciliation Engine (/api/now/identifyreconcile) batch.

      By default (rule SN4), all CMDB previews use pseudonymized identifiers (<pool-1>, <host-1>). Opting in to estate identifiers emits ARM IDs for live IRE ingestion.

      2. Drift & Change Reconciler (C21 & C24)

      Deduplicate C21 assessment gaps into ServiceNow problem records keyed by correlation_id and map C24 remediation waves into phased change_request records.

      3. Swarm Incident Intake & Known Error Bridge

      Test inbound ServiceNow incident scrubbing (rule SN2), Prompt Shields injection detection, threadStartedBy: alert provenance (V1-4), and Known Error (kb_template_known_error) generation.

      4. Validate Envelope & Cloud Shell Runner

      Validate an avd-itsm-sync-envelope/v1 (C26 candidate) JSON file offline in your browser, or copy a standalone Cloud Shell command block.
